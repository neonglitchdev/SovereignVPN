# Ipotesi [H] in vigore

Dove il PRD+RFC 14.0.0 non decide, il codice usa un'ipotesi dichiarata: si marca [H] nel codice e nel rapporto, e si
chiude nel documento (regola di CLAUDE.md). Ognuna si rovescia cambiando una riga.
